# Interface snapshots

Rendered by `WorldbuilderTests --snapshots docs/snapshots <prefix>` (the real editor at
100 %, 1160 x 812). `before-*` is Milestone 9; `after-*` is Milestone 10 (planet globe and
the restyled controls). Compare pairs with the same name:

| Name | What |
|---|---|
| `full-default`, `full-world` | the whole editor: one Castle; Castle, Village, Spaceport and Forest |
| `header`, `controls`, `bottom` | the top bar; the World Controls; Locations, settings and Capture |
| `cards`, `cards-scifi` | the Place selector (all, sci-fi) |
| `strips` | the environment mixer and the Place strips |
| `detail`, `patterns` | a Place's detail panel; the Pattern Editor |
| `globe-places`, `globe-frozen`, `globe-scorching`, `globe-storm`, `globe-city` | the globe in several worlds |
| `globe-planet-*` (after only) | the globe on each planet type |
